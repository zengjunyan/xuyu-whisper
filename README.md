# 絮语 Whisper

一个极简的本地动态应用：发布、浏览、点赞，数据保存在你自己的浏览器里；界面会随系统明暗自动切换，背景是一组暖调壁纸，每个整点换一张。

纯 HTML + CSS + JavaScript 实现，无框架、无构建工具、无外部请求，双击即可离线使用。

## 运行

直接双击 `index.html`，或在文件所在目录启动一个静态服务器：

```bash
python -m http.server 8765
```

然后访问 <http://localhost:8765/>。

> 提示：`file://` 协议下部分浏览器会限制 localStorage。若发现刷新后内容丢失，请用本地服务器方式打开。

## 功能

- **发布**：顶部发布框输入文字，点「发布」或按 `Ctrl / ⌘ + Enter` 提交；上限 280 字，接近上限时计数变色。
- **查看**：卡片式时间线，按发布时间倒序，显示头像、昵称、相对时间与正文；超过 4 行折叠为「展开全文」。
- **点赞**：即时切换已赞 / 未赞，计数同步并持久保存。
- **主题跟随系统**：默认跟随系统深浅色，系统切换时页面立即响应；右上角按钮按「跟随系统 → 浅色 → 深色」循环，按钮上的小圆点表示当前处于跟随状态，选择会被记住。
- **整点换背景**：内置 8 张暖调壁纸，按当前整点确定性轮换（同一小时看到同一张），跨整点自动交叉淡化，页面不刷新；右上角图片按钮可手动「换一张」，手动选择在本小时内有效，下个整点自动回到排期。
- **可读性优先**：壁纸之上叠加随主题变化的柔和遮罩与细颗粒纸纹，卡片使用半透明玻璃质感，图片加载失败时回落为暖色渐变。
- **响应式与可访问性**：桌面 680px 单列，移动端自适应全宽；按钮带 `aria-label`，Toast 使用 `aria-live`，尊重 `prefers-reduced-motion`。

## 壁纸轮换规则

```js
slot  = Math.floor(Date.now() / 3600000);   // 当前小时序号
index = slot % 8;                            // 对应 assets/bg-01 ~ bg-08
```

- 当前小时内的排期是确定的，同一小时内多次打开看到同一张。
- 整点后在原画面上淡入下一张（约 900ms），内容与滚动位置不受影响。
- 手动「换一张」只作用于当前小时；整点切换会清空手动选择。
- 下一张会在空闲时预加载并 `decode()`，避免切换时出现空白帧。

## 数据说明

localStorage 使用两个键：

| 键名 | 内容 |
| --- | --- |
| `whisper.posts.v1` | 动态数组（JSON） |
| `whisper.theme.v2` | 主题偏好：`system` / `light` / `dark` |

单条动态结构：

```json
{
  "id": "p_mp3k2x_9f1a",
  "author": "我自己",
  "createdAt": 1763000000000,
  "content": "动态正文",
  "likes": 3,
  "likedByMe": true
}
```

首次打开会写入 4 条原创示例动态作为演示。清空站点数据即可恢复初始示例。

> 旧版本使用的 `whisper.theme.v1` 在首次启动时会被自动清理，统一回到「跟随系统」。

## 实现要点

- 正文一律通过 `textContent` 写入，天然避免 XSS。
- 读取 localStorage 全程 `try / catch`：数据损坏、格式不符时回退到示例数据，不白屏；写入失败时降级为仅内存可用并提示一次。
- 主题在首屏绘制前由 `<head>` 内联脚本写入 `data-theme`，避免明暗闪烁；`matchMedia('(prefers-color-scheme: dark)')` 监听系统变化，仅在「跟随系统」模式下生效。
- 壁纸使用固定定位的双层容器做交叉淡化，只改变 `opacity` / `transform`；切换请求带序号，连续点击不会被旧图片覆盖。
- 图片通过 `new Image()` 预加载，超时 4 秒视为失败；失败时保留遮罩并展示暖色渐变，不会出现白屏。
- 场景层 `pointer-events: none` 且位于内容之下，不影响滚动与点击。
- 浅色主题遇到底色较暗的壁纸（灯下 / 夜窗）会自动加强遮罩，正文对比度保持可读。
- `backdrop-filter` 不支持时回退为不透明卡片；`prefers-reduced-motion` 下所有过渡瞬间完成。

## 命名与素材

「絮语 Whisper」为原创命名，界面文案、图标、图标内 SVG 与全部壁纸均为原创或 AI 生成，不含任何第三方平台的名称、标识或品牌元素；壁纸为本地文件，页面运行时不发起任何网络请求。
